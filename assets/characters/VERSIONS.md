# Character art versions — compare & finalize

Convention: **never overwrite** a pass you might still want.  
- New attempts get a new filename: `{id}-v{N}-{short-label}.jpg`  
- `*-portrait.jpg` / `*-reference.jpg` (no version) = **default / identity base** for game wiring (edit-chain source).  
- When identity locks (face, hair, outfit, props), we stop redesigning the person — we **add expression/context variants** from that base.

## Standing rule — multi-expression, multi-context (owner)

Characters are **not** one fixed face forever. Default portrait = identity + neutral “cast tone.”  
Additional assets should cover **mood, conversation, and place** (e.g. cool dock, heritage weight, rivalry banter, tired after a bad hop).  
Same person, same design language; expression/posture/lighting shift. Keep both Jex v1 (sharp/smirk) and v2 (heavier) as valid *states*, not competing finals.
